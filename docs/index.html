FIELD NOTES01 — 04
01 THE IDEA

There is no single
“ethical” score.

Responsible sourcing touches many things: workers’ voices, wages, environmental practices, and how concerns are resolved. A disclosure can be a useful starting point — but it is not proof that a practice is happening.

This demo makes gaps visible instead of hiding them inside a rating. Use the filter to explore different kinds of example evidence. The profiles are not ranked, and the order is not meaningful.
