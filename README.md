# Sourcing Signals

An educational ethical-sourcing demo about reading supplier disclosures carefully. The site uses fictional supplier profiles to show why evidence, gaps, and context matter — without ranking suppliers or making real-world claims.

## View the project

- **Website:** https://belianakrashi.github.io/Beliana-Krashi-Project-1/
- **GitHub repository:** https://github.com/belianakrashi/Beliana-Krashi-Project-1

The site is plain HTML, CSS, and JavaScript, published from [`docs/`](./docs/). There is no build step or server.

## Preview locally

Open `docs/index.html` in a browser, or serve the `docs/` directory with any local static file server. No packages or API keys are required.

## Important limitations

All supplier names and evidence examples are invented for learning. The labels describe the source of fictional information, not actual performance. This prototype is not an audit, certification, or purchasing recommendation, and it collects no visitor data.
